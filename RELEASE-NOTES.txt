NextUI compatibility release based on wild1walker's PortMaster Cuphead **2026.10.28.3**.

- Fix the reported startup crash by selecting native TrimUI EGL/GLES libraries.
- Route 64-bit audio through system aplay at stereo 48 kHz with a 160 ms buffer to address the reported repeating/stuck audio.
- Detect NextUI PortMaster via EMU_DIR; disable diagnostic shim tracing.

Downloads:
- **cuphead-nextui-2026.10.31.zip**: port/runtime/setup files plus the launchers; install PortMaster for NextUI separately.
- **cuphead-nextui-scripts-2026.10.31.zip**: only launchers and notices for existing upstream 2026.10.28.3 installations.
- **SHA256SUMS.txt**: checksums.

Extract into `Roms/Ports (PORTS)/.ports/`. See the repository README for menu-script placement and setup. Supply your own supported GOG macOS game copy for conversion.

No Cuphead game files, converted game APK/OBB, installers, saves or personal logs are included. Upstream's blank Unity donor APKs and runtime dependencies remain in the full package.

The graphics and aplay route were reported working on the owner's NextUI device. This clean package was reconstructed from the pinned upstream release and checked offline; fresh conversion and the release ZIP have not been tested on hardware. Other devices remain unverified.

Original port and runtime credit: wild1walker and contributors. NextUI compatibility adjustments: nightmoon-kill. Upstream licences and third-party notices are preserved.
